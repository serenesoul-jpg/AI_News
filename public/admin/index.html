🧊 日报内容管理

预览前台
📋 填写说明（不需要写 JSON，按表单填写即可）
  • 新闻标题：一句话概括，建议 20～40 字
  • 新闻正文：完整报道内容，直接粘贴纯文字即可
  • 来源链接：点击「添加来源」填写来源名称和网址，可添加多条
  • 解读内容：AI 科技填「深度解读」，教育填「教育观察」，文化填「文化观察」
  • 每天三个板块（AI 科技 / AI+教育 / AI+文化）分别添加新闻，填完点「发布」即可上线
  • 前台默认显示当天日报：发布今日内容会更新首页；补发历史日期只存档，不会改变首页展示
  • 如果从扣子生成了 HTML 文件，可用「导入 HTML」一键解析

从 HTML 导入

将扣子生成的 HTML 文件内容粘贴到下方，或上传 .html 文件
